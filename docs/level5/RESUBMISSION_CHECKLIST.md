# Level 5 Resubmission Checklist

Use this checklist before resubmitting the GitHub repository link.

## Required Links

- Public GitHub repository: ready.
- Live deployed application: ready.
- PPT/Pitch deck link: ready in `docs/pitch/ProofDesk_Level5_Pitch_Deck.pptx`.
- Demo video link: paste the final walkthrough URL after recording.
- Google Form link: paste the live form URL after creating the form.
- Exported Excel sheet: keep `docs/evidence/proofdesk-level5-user-feedback.xlsx` updated with real responses.

## Required Proof

- Minimum 50+ Testnet users onboarded.
- Each counted user must include wallet address, name, email, rating, feedback, and signed transaction proof.
- Real transaction activity must be shown with transaction hash or Stellar explorer URL.
- Active usage proof must be supported by analytics or transaction screenshots.

## Documentation

- README must include the Excel sheet link.
- README must outline next-phase improvements from collected feedback.
- README improvement section must include commit links.
