# Level 5 Pitch Deck Requirement Map

The Level 5 pitch deck must explain these points.

| Required topic | ProofDesk slide/content |
|---|---|
| Problem statement | Private document proof is hard to verify publicly without exposing document content. |
| Solution | ProofDesk stores only SHA-256 fingerprints on Stellar Testnet. |
| Market opportunity | Certificates, agreements, invoices, audit trails, and bootcamp/community credentials. |
| Architecture | React frontend, Freighter wallet, local hashing, Soroban contract, Stellar Testnet. |
| Growth strategy | 50+ tester cohort, Google Form feedback, user batches, transaction proof tracking. |
| Future roadmap | Shareable certificates, proof history, batch proofs, hosted analytics, mainnet readiness. |
