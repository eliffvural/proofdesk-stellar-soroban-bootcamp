# Level 5 Analytics and Transaction Screenshot Checklist

Level 5 requires screenshots of analytics or transaction activity.

## Screenshots To Capture

- Level 5 validation drawer after real tester activity.
- Evidence export summary showing signed wallet count.
- Stellar explorer page for a real ProofDesk transaction.
- Google Form response count.
- Excel analysis sheet with 50+ rows or summarized totals.

## Naming Recommendation

- `docs/screenshots/level5-growth-dashboard.png`
- `docs/screenshots/level5-transaction-activity.png`
- `docs/screenshots/level5-feedback-analysis.png`

Only use screenshots from real tester activity.
