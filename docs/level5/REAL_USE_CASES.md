# Level 5 Real Use Cases

The Level 5 demo and pitch should show practical usage, not only smart contract mechanics.

## Use Cases

### Certificate Verification

Use ProofDesk to prove a certificate existed without uploading the certificate file.

### Agreement Proof

Hash an agreement text locally and store the fingerprint on Stellar Testnet.

### Invoice Proof

Create a proof that an invoice version existed at a point in time.

### Audit Trail

Use signed wallet ownership and revocation state to show whether a proof is still trusted.
