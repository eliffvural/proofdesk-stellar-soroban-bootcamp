# Level 5 Excel Export and Analysis

The exported Excel workbook is the source of truth for the 50+ user proof.

## Workbook Location

`docs/evidence/proofdesk-level5-user-feedback.xlsx`

## Required Sheets

- `Form Responses`: raw Google Form export rows.
- `Analysis`: user count, unique wallet count, signed transaction count, average rating, top feedback themes.
- `Improvement Backlog`: feedback themes mapped to planned product improvements and commit links.

## Minimum Analysis Fields

- Total responses.
- Unique wallet addresses.
- Count of rows with transaction proof.
- Average product rating.
- Top three feedback themes.
- Improvement commit link for each completed iteration.
