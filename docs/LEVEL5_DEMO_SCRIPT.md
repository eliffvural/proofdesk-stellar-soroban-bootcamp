# ProofDesk Level 5 Demo Video Script

Target length: 5 to 7 minutes.

## 1. Opening

Show the live URL:

https://eliffvural.github.io/proofdesk-stellar-soroban-bootcamp/

Say:

ProofDesk is a Stellar Soroban dApp for private document proof and public verification. The app keeps document content local, stores only a SHA-256 fingerprint on-chain, and lets users verify or revoke proofs with wallet ownership.

## 2. Wallet and Testnet Setup

1. Open Freighter.
2. Confirm the wallet is on Stellar Testnet.
3. Connect the wallet in ProofDesk.
4. Show the connected wallet chip and contract metrics.

## 3. Create a Proof

1. Use harmless sample text, not a private document.
2. Click Generate hash.
3. Explain that the fingerprint is created locally in the browser.
4. Click Save proof.
5. Approve the Freighter signature.
6. Copy or open the transaction hash / Stellar explorer link.

## 4. Verify and Revoke

1. Show the owner wallet and proof fingerprint fields.
2. Click Verify proof.
3. Show the valid proof result.
4. Click Revoke my proof.
5. Approve the wallet signature.
6. Verify again and show that the proof is inactive/revoked.

## 5. Level 5 Growth Dashboard

Open the Level 5 growth validation drawer and show:

- 50 signed-wallet onboarding target
- Analytics event count
- Wallet interaction count
- Monitoring issue count
- Feedback response count
- Export Level 5 evidence button
- Export feedback CSV button
- Tester feedback form with name, email, use case, rating, and feedback

## 6. Google Form and Excel Evidence

Show:

- The live Google Form URL after it is created
- The required fields: wallet address, email, name, rating, feedback, transaction proof
- The Excel workbook at `docs/evidence/proofdesk-level5-user-feedback.xlsx`
- The `Analysis` sheet with target users, unique wallets, signed transactions, average rating, and feedback themes

## 7. Pitch and Roadmap

Briefly show the pitch deck:

`docs/pitch/ProofDesk_Level5_Pitch_Deck.pptx`

Mention the next planned improvements:

- Shareable verification certificate
- Batch proof creation
- Proof history and saved hashes
- Hosted analytics endpoint
- Mainnet readiness checklist

## 8. Closing Checklist

End by showing the README Level 5 section and confirm:

- Public GitHub repository
- Live deployed application
- Pitch deck link
- Demo video link
- Feedback workbook link
- Google Form link
- Proof of 50+ users with signed Testnet activity
- Analytics or transaction screenshots
- Feedback-driven iteration summary with commit links
